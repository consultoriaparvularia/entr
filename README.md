Aplicación ENT R

Aplicación móvil desarrollada en React Native con Expo, que presenta una serie de ejercicios interactivos basados en imágenes y audio, donde el usuario selecciona respuestas que se almacenan.

Tecnologías utilizadas

React Native
Expo
JavaScript

Estructura del Proyecto

/screens    # Ejercicios de la aplicación
/assets     # Imágenes y audios
/styles     # Estilos globales
/context    # Manejo de estado (respuestas)

Funcionamiento de la Aplicación
Ejercicios (screens/)

Cada archivo representa un ejercicio:

Ejercicio01Screen.js
Ejercicio02Screen.js
...
Ejercicio10Screen.js

Lógica de cada ejercicio

Cada pantalla incluye:

Reproducción de audio
Interacción con imágenes
Selección de respuestas
Navegación al siguiente ejercicio

Recursos (assets/)

Contiene:

Imágenes (.png, .jpg)
Audios (.mp3)
